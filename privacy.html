Privacy Policy

This policy explains how 오아영 채널 도구 (Oayeong Channel Tool) ("the tool") accesses, collects, stores, uses, shares and deletes data. The tool is an internal tool for one YouTube channel, 촉이 오아영 ChokA0 (channel ID UCvHOjrz1843NFK7rkyPQ2ug). It is run by the channel's editor ("the operator") on one Windows PC and is not offered to anyone else. The only person who authorizes the tool is the owner of that channel ("the channel owner"). Authorizing the tool means agreeing to this policy.

1. YouTube API Services

The tool uses YouTube API Services: the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API.

  • YouTube Terms of Service: https://www.youtube.com/t/terms
  • Google Privacy Policy: http://www.google.com/policies/privacy

2. Data the tool accesses, collects, stores and uses

The tool only works with the channel above. For each kind of data, this section says where it comes from, why the tool needs it, where it is kept and how long.

2.1 Google sign-in authorization

What
The access and refresh tokens Google issues when the channel owner authorizes the tool, for two permissions: managing the channel's YouTube content (youtube.force-ssl) and viewing its YouTube Analytics reports (yt-analytics.readonly).
Why
To make the API requests listed below on the channel's behalf.
Where
A folder on the operator's PC that is not synced to any cloud storage. The tool never displays the tokens.
How long
Until the channel owner revokes access or the tool is retired. The tokens are then deleted.

2.2 Caption tracks of the channel's videos

What
The list of caption tracks on the channel's own videos (track ID, language, name, status), read with captions.list. The tool adds, replaces and removes the channel's own caption tracks with captions.insert, captions.update and captions.delete. The subtitle text is written by the channel team.
Why
To publish subtitles in 14 languages and to replace the right track when a subtitle is corrected.
Where
Track IDs and upload records (language, time, file fingerprint) are kept with the subtitle work files in the operator's project folder on the same PC.
How long
While the video's subtitles are maintained. The tool reads the current track list from YouTube again before every upload.

2.3 Titles and descriptions of the channel's videos

What
The title, description and existing translations of the channel's own videos, read with videos.list. The tool adds translated titles and descriptions with videos.update.
Why
To translate them and publish the translations on the same video.
Where
A working copy is kept next to the subtitle work files in the operator's project folder.
How long
While the video's translations are maintained. Report data files refresh the titles of the channel's videos from the latest collection, and replace them with the video ID if no collection from the last 30 days exists.

2.4 Channel analytics and public statistics

What
Aggregated reports about the channel from the YouTube Analytics API and the YouTube Reporting API: views, watch time, average view duration and percentage, subscribers gained and lost, likes, comments and shares; traffic sources and YouTube search terms; country; content type (long-form or Shorts); audience retention; thumbnail impressions and click-through rate; views by subtitle language. Also the public view, like, comment and subscriber counts of the channel and its videos (channels.list for the signed-in channel, playlistItems.list on the channel's uploads list, videos.list). These reports are aggregates; they do not identify individual viewers.
Why
To build the weekly report for the channel owner and to show how the numbers change over time.
Where
A local data folder on the operator's PC, outside the project folder and not synced to any cloud storage.
How long
Kept so the report can show trends. At least every 30 days the operator confirms that the tool is still authorized (each collection makes authorized requests, and the clean-up command warns when the last successful one is older than 30 days). If access has been revoked, the stored data is deleted.

2.5 Comments and other channels' videos

The tool does not read comment text, commenters' names or details of other channels' videos. Copies collected before November 6, 2026 are deleted within 30 days of collection by an automatic clean-up.

2.6 What the tool does not collect

The tool does not collect comment text, data about other channels, or the channel owner's or viewers' email addresses, contacts, payment details or location, does not upload videos and does not use YouTube search. It does not use this data for advertising, profiling or any purpose other than the two described here: publishing subtitles and translations on the channel's own videos, and reporting to the channel owner.

3. How data is used and shared

The data is used only by the operator, for the channel owner. It is not sold, rented or traded. It is shared only as follows:

  • The channel owner receives the weekly report by email at her own two email addresses. The operator receives a copy.
  • Email services. Reports are sent from the operator's Gmail account over an encrypted connection, so they are stored by Google (Gmail) and by the email service of each recipient (one Gmail address and one Naver Mail address of the channel owner).
  • Anthropic (Claude). The operator uses Claude, an AI assistant provided by Anthropic, on the same PC to draft subtitle translations and to write the text of the weekly report. When it does so, the data needed for that task is sent to Anthropic for processing: subtitle text, titles and descriptions, and statistics. See Anthropic's privacy policy.
  • YouTube. Subtitles, translated titles and translated descriptions are published on the channel's own videos through the YouTube API.
  • When the law requires it. If a valid legal request requires disclosure.

4. Where data is stored and how it is protected

Analytics data and statistics, and the reports made from them, are stored only in local folders on the operator's PC and are not synced to cloud storage. The authorization tokens are kept in a separate local folder that is also not synced. The tool has no server and no database of its own. Report emails are sent over an encrypted (SSL) connection.

5. Cookies, device storage and ads

The tool does not place cookies or read or store information on anyone else's device. It shows no ads and no third-party content. This website uses no cookies, trackers or analytics; the web host may keep standard server access logs.

6. Revoking access and deleting data

  • The channel owner can revoke the tool's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Revoking stops all API access immediately.
  • If access is revoked, or if the channel owner asks for her data to be deleted, the operator deletes the stored tokens and the stored API data from the operator's PC within 7 days.
  • Reports already delivered to the channel owner's mailboxes stay under her control.

7. Changes to this policy

When this policy changes, the date at the top of this page changes, and the channel owner is told about significant changes before they take effect.
